CHROME-HINWEIS UND TESTANLEITUNG

Warum es in Google Chrome manchmal nicht funktioniert:
1. Wenn die Website direkt aus der ZIP-Datei geöffnet wird, fehlen Chrome oft die Unterordner
   wie global/, shop/, modelle/ oder main web/. Dann können CSS und JavaScript nicht korrekt laden.
2. Chrome kann localStorage bei lokalen Dateien oder strengen Datenschutz-Einstellungen blockieren.
   Die Übersetzungsfunktion wurde deshalb jetzt mit einem Fallback repariert.
3. Die automatische Browser-Übersetzung von Chrome ist bei lokalen HTML-Dateien unzuverlässig.
   Deshalb hat die Website jetzt einen eigenen DE/EN-Sprachumschalter.

So startest du die Website richtig:
1. ZIP-Datei entpacken.
2. Den ganzen entpackten Ordner in VS Code öffnen.
3. index.html mit Live Server starten.
4. Unten rechts auf EN oder DE klicken.
5. Danach durch die Seiten klicken. Die Sprache bleibt erhalten.

Technische Änderung:
- global/translate-interactive.js wurde Chrome-sicher gemacht.
- Die Sprache funktioniert jetzt auch dann, wenn localStorage blockiert ist.
- Zusätzlich wird die Sprache über ?lang=en oder ?lang=de beim Seitenwechsel mitgegeben.
