Website sauber starten

Die ZIP-Datei zuerst vollständig entpacken. Für die zuverlässigste Präsentation sollte die Website über einen lokalen Webserver geöffnet werden.

Empfohlener Start

  1. Projektordner in Visual Studio Code öffnen.
  2. index.html mit der Erweiterung „Live Server“ starten.
  3. Alternativ im Projektordner python -m http.server 8000 ausführen.
  4. Im Browser http://localhost:8000 öffnen.

Vor der Präsentation

  • Startseite, mobile Navigation, Suche, Slider und Sprachumschaltung testen.
  • Im Demo-Shop einen Artikel bis zur Bestellbestätigung durchspielen.
  • README-PDF und Projektseite für die technische Erklärung bereithalten.
